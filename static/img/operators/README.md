# Operator logos

Drop the five brand logos here with exactly these names:

| file | operator |
|---|---|
| `tsel.png` | Telkomsel |
| `xl.png` | XL Center |
| `im3.png` | IM3 / Gerai Indosat |
| `3id.png` | 3Store (Tri) |
| `smartfren.png` | Smartfren |

`.png` with a transparent background is ideal; `.svg`, `.jpg` and `.webp`
also work — change the filename in `config.OPERATORS` to match.

Square-ish crops render best. They are drawn at about 20px on the map, so
anything above 128px square is plenty and anything wider than it is tall
will be letterboxed into the square.

**Any file that is missing is simply skipped** — that operator keeps its
coloured dot, on the map and in the legend. Nothing errors, so you can add
them one at a time.

These are third-party trademarks used here to identify competitor outlets
in an internal tool. Supply the files yourself rather than having them
fetched, so provenance and permission stay yours.
